# CatKey Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An AutoHotkey v2 script that, after a hardcoded idle timeout, swallows all keys, dims every monitor with "CatKey locked", sets the power/sleep buttons to "Do nothing", and undoes all of it on a double-click anywhere.

**Architecture:** Four small classes in `lib/` with one job each — `PowerButtons` (Windows power API + crash-safe state file), `KeyBlock` (suppressing `InputHook`), `Overlay` (one tinted GUI per monitor, double-click detection), `CatKeyController` (locked/paused state, idle check, ordering). `CatKey.ahk` only wires real instances together, sets up the tray menu and a 1 s timer. Every class is tested by a standalone AHK test script that prints `PASS`/`FAIL` lines to stdout and exits non-zero on failure.

**Tech Stack:** AutoHotkey v2.0 (installed at `C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe`, v2.0.23), Win32 `powrprof.dll` via `DllCall`, PowerShell 7 test runner.

**Spec:** `docs/superpowers/specs/2026-10-30-catkey-design.md`

## Global Constraints

- AutoHotkey v2 only: every `.ahk` file starts with `#Requires AutoHotkey v2.0`. No external libraries.
- Runs unelevated. No admin-only APIs.
- Timeout is a hardcoded constant at the top of `CatKey.ahk`: `IdleTimeoutMin := 5`.
- Overlay text is exactly `CatKey locked`; black tint at opacity `77` (≈30%) via `WinSetTransparent`; white text, centered.
- Idle uses `A_TimeIdlePhysical` (keyboard + mouse hooks installed), polled every 1000 ms.
- Power settings touched: subgroup `{4f971e89-eebd-4455-a8de-9e59040e7347}` (SUB_BUTTONS), settings `{7648efa3-dd9c-4e3e-b566-50f929386280}` (PBUTTONACTION) and `{96996bc0-ad50-47ec-923b-6f41874dd9eb}` (SBUTTONACTION), both AC and DC. "Do nothing" = `0`.
- State file: `CatKey.state` (INI, section `[Saved]`, keys `PowerAC`, `PowerDC`, `SleepAC`, `SleepDC`) next to the script; exists only while buttons are disabled.
- Tray menu items, in order: `Lock now`, `Pause CatKey` (checkmark when paused), separator, `Exit`.
- Git commits: never add Claude as author or co-author (user's global rule).

Deviation from the spec's wording: the spec mentions the `powercfg` tool; the plan calls the same Windows power API that `powercfg` uses (`powrprof.dll`) directly — same settings, no console windows, no output parsing.

Verified on this machine before planning (do not re-litigate): `PowerReadACValueIndex`/`PowerWriteACValueIndex` succeed unelevated; AHK GUI windows have `CS_DBLCLKS`, so a double-click arrives as `WM_LBUTTONDBLCLK` (0x203); `InputHook` with `VisibleText/VisibleNonText := false` + `KeyOpt("{All}", "S")` swallows `SendEvent` input; `FileAppend(..., "*")` output and `ExitApp(n)` codes reach PowerShell; `/Validate` checks a script without running it.

## Review Focus

1. **Power API fails** (policy-managed machine, odd scheme) → keyboard must still lock and overlay still show; error is swallowed, not a crash. Test: Task 5 `"lock survives power failure"`.
2. **Lock requested while already locked** (tray "Lock now" + timer tick) → saved originals must never be overwritten with the zeros. Tests: Task 2 `"second Disable keeps originals"`, Task 5 `"Lock is idempotent"`.
3. **Corrupt or partial `CatKey.state` at startup** → no exception, file removed, current settings left alone. Test: Task 2 `"corrupt state file"`.
4. **Multiple monitors / scaled displays** → each overlay window covers its monitor exactly in physical pixels (`-DPIScale`). Test: Task 4 `"window N covers monitor N"`.
5. **Double-click on a window that isn't the overlay, or after unlock** → must not unlock/fire. Tests: Task 4 `"foreign window ignored"`, `"no callback after Hide"`.

**Interfaces:**
- Consumes: `tests/Assert.ahk`.
- Produces:
  - `PowerButtons.Read()` (static) → `Map("PowerAC", n, "PowerDC", n, "SleepAC", n, "SleepDC", n)`, integers. Throws `OSError` on API failure.
  - `PowerButtons.Write(values)` (static) — `values` is a Map with those four keys; writes and re-applies the active scheme. Throws `OSError` on failure.
  - `PowerButtons(stateFile)` → instance with `.StateFile`.
  - `.Disable()` — saves current values to `StateFile` **only if the file does not already exist**, then writes all four to `0`.
  - `.Restore()` → `true` if values were restored from `StateFile` (file then deleted); `false` if no file, or the file was corrupt (file deleted, settings untouched). Throws if the write fails (file kept, so the next start retries).

**Note:** this test changes your real power-button settings for a moment and puts them back in a `finally` block. If the test process is killed mid-run, run `powercfg /qh SCHEME_CURRENT SUB_BUTTONS` to check, or start CatKey (it restores from `CatKey.state` — but the test uses a temp state file, `%TEMP%\CatKey.test.state`; delete/restore manually from it if needed).

```ahk
#Requires AutoHotkey v2.0

; Saves, disables and restores the physical power/sleep button actions of the
; active power scheme. The originals are kept in a state file while disabled,
; so a crash while locked can be repaired on the next start.
class PowerButtons {
    static SubButtons := "{4f971e89-eebd-4455-a8de-9e59040e7347}"
    static Settings := Map(
        "Power", "{7648efa3-dd9c-4e3e-b566-50f929386280}",
        "Sleep", "{96996bc0-ad50-47ec-923b-6f41874dd9eb}")
    static Keys := ["PowerAC", "PowerDC", "SleepAC", "SleepDC"]

    __New(stateFile) {
        this.StateFile := stateFile
    }

    Disable() {
        if !FileExist(this.StateFile) {
            for key, value in PowerButtons.Read()
                IniWrite(value, this.StateFile, "Saved", key)
        }
        PowerButtons.Write(Map("PowerAC", 0, "PowerDC", 0, "SleepAC", 0, "SleepDC", 0))
    }

    Restore() {
        if !FileExist(this.StateFile)
            return false
        values := Map()
        for key in PowerButtons.Keys {
            value := IniRead(this.StateFile, "Saved", key, "")
            if !IsInteger(value) {
                FileDelete(this.StateFile)
                return false
            }
            values[key] := Integer(value)
        }
        PowerButtons.Write(values)
        FileDelete(this.StateFile)
        return true
    }

    static Read() {
        values := Map()
        scheme := PowerButtons._ActiveScheme()
        try {
            sub := PowerButtons._Guid(PowerButtons.SubButtons)
            for name, guid in PowerButtons.Settings {
                setting := PowerButtons._Guid(guid)
                for mode in ["AC", "DC"] {
                    r := DllCall("powrprof\PowerRead" mode "ValueIndex", "Ptr", 0, "Ptr", scheme
                        , "Ptr", sub, "Ptr", setting, "UInt*", &value := 0, "UInt")
                    if r
                        throw OSError(r, "PowerRead" mode "ValueIndex")
                    values[name mode] := value
                }
            }
        } finally {
            DllCall("LocalFree", "Ptr", scheme)
        }
        return values
    }

    static Write(values) {
        scheme := PowerButtons._ActiveScheme()
        try {
            sub := PowerButtons._Guid(PowerButtons.SubButtons)
            for name, guid in PowerButtons.Settings {
                setting := PowerButtons._Guid(guid)
                for mode in ["AC", "DC"] {
                    r := DllCall("powrprof\PowerWrite" mode "ValueIndex", "Ptr", 0, "Ptr", scheme
                        , "Ptr", sub, "Ptr", setting, "UInt", values[name mode], "UInt")
                    if r
                        throw OSError(r, "PowerWrite" mode "ValueIndex")
                }
            }
            r := DllCall("powrprof\PowerSetActiveScheme", "Ptr", 0, "Ptr", scheme, "UInt")
            if r
                throw OSError(r, "PowerSetActiveScheme")
        } finally {
            DllCall("LocalFree", "Ptr", scheme)
        }
    }

    static _ActiveScheme() {
        r := DllCall("powrprof\PowerGetActiveScheme", "Ptr", 0, "Ptr*", &scheme := 0, "UInt")
        if r
            throw OSError(r, "PowerGetActiveScheme")
        return scheme
    }

    static _Guid(str) {
        buf := Buffer(16)
        DllCall("ole32\CLSIDFromString", "WStr", str, "Ptr", buf, "HRESULT")
        return buf
    }
}
```

```ahk
#Requires AutoHotkey v2.0

; Swallows every keystroke while active. The mouse is not affected.
class KeyBlock {
    __New() {
        this._hook := InputHook("L0")
        this._hook.VisibleText := false
        this._hook.VisibleNonText := false
        this._hook.KeyOpt("{All}", "S")
    }

    IsActive => this._hook.InProgress

    Start() {
        if !this._hook.InProgress
            this._hook.Start()
    }

    Stop() {
        if this._hook.InProgress
            this._hook.Stop()
    }
}
```

```ahk
#Requires AutoHotkey v2.0

; Dims every monitor with an always-on-top window showing a message. The windows
; catch all mouse clicks; a double-click on any of them calls OnUnlock.
class Overlay {
    static WM_LBUTTONDBLCLK := 0x203

    __New(text := "CatKey locked", opacity := 77) {
        this.Text := text
        this.Opacity := opacity
        this.OnUnlock := ""
        this._guis := []
        this._onDblClick := ObjBindMethod(this, "_HandleDblClick")
    }

    IsShown => this._guis.Length > 0

    Hwnds {
        get {
            hwnds := []
            for g in this._guis
                hwnds.Push(g.Hwnd)
            return hwnds
        }
    }

    Show() {
        if this.IsShown
            return
        Loop MonitorGetCount() {
            MonitorGet(A_Index, &left, &top, &right, &bottom)
            w := right - left, h := bottom - top
            ; -DPIScale: MonitorGet returns physical pixels, so size the window in pixels too
            g := Gui("+AlwaysOnTop -Caption +ToolWindow -DPIScale")
            g.BackColor := "000000"
            g.SetFont("s48 cWhite", "Segoe UI")
            g.AddText("x0 y" (h // 2 - 60) " w" w " h120 Center BackgroundTrans", this.Text)
            g.Show("x" left " y" top " w" w " h" h " NA")
            WinSetTransparent(this.Opacity, "ahk_id " g.Hwnd)
            this._guis.Push(g)
        }
        OnMessage(Overlay.WM_LBUTTONDBLCLK, this._onDblClick)
    }

    Hide() {
        if !this.IsShown
            return
        OnMessage(Overlay.WM_LBUTTONDBLCLK, this._onDblClick, 0)
        for g in this._guis
            g.Destroy()
        this._guis := []
    }

    KeepOnTop() {
        for g in this._guis
            WinSetAlwaysOnTop(1, "ahk_id " g.Hwnd)
    }

    _HandleDblClick(wParam, lParam, msg, hwnd) {
        ; Clicks on the text control land on the window itself (static controls
        ; are click-transparent), but check the root window to be safe.
        root := DllCall("GetAncestor", "Ptr", hwnd, "UInt", 2, "Ptr")
        for g in this._guis {
            if (g.Hwnd = root) {
                if this.OnUnlock
                    SetTimer(this.OnUnlock, -1)
                return 0
            }
        }
    }
}
```

```ahk
#Requires AutoHotkey v2.0

; Owns the locked/paused state and drives the keyboard block, overlay and power
; buttons in a fixed order. Power-button errors never stop the keyboard lock.
class CatKeyController {
    __New(timeoutMs, overlay, keyBlock, powerButtons) {
        this.TimeoutMs := timeoutMs
        this.Overlay := overlay
        this.KeyBlock := keyBlock
        this.PowerButtons := powerButtons
        this.Locked := false
        this.Paused := false
        this.LastError := ""
        overlay.OnUnlock := ObjBindMethod(this, "Unlock")
    }

    ; Called once a second with A_TimeIdlePhysical.
    Tick(idleMs) {
        if this.Locked
            this.Overlay.KeepOnTop()
        else if !this.Paused && idleMs >= this.TimeoutMs
            this.Lock()
    }

    Lock() {
        if this.Locked
            return
        this.Locked := true
        this.KeyBlock.Start()
        this.Overlay.Show()
        try {
            this.PowerButtons.Disable()
        } catch as e {
            this.LastError := e.Message
        }
    }

    Unlock() {
        if !this.Locked
            return
        this.Locked := false
        this.Overlay.Hide()
        this.KeyBlock.Stop()
        try {
            this.PowerButtons.Restore()
        } catch as e {
            this.LastError := e.Message
        }
    }

    TogglePause() {
        this.Paused := !this.Paused
        return this.Paused
    }

    ; Repairs button actions left disabled by a crash while locked.
    RecoverFromCrash() {
        try {
            this.PowerButtons.Restore()
        } catch as e {
            this.LastError := e.Message
        }
    }

    Shutdown() => this.Unlock()
}
```
